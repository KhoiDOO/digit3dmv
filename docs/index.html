Dual-Level Multi-View PixelDiT Architecture

Decoupling global multi-view 3D context in patch space from fine geometric normal refinement in pixel space.

3D-RoPE Embeddings

Extends rotary position embeddings to 3D space by allocating dedicated rotary frequencies across View Index ($V$) and Image Coordinates ($H, W$).

Dual-Level Space

Global patch tokens capture multi-view topological consistency, while local sub-patch pixel tokens preserve sharp surface normal contours.

Flow Matching ODE

Rectified linear probability paths connecting Gaussian noise directly to multi-view normal distributions in only 25 Euler steps.
