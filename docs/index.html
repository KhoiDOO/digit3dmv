Digit3D-MV: Multi-View Geometry Synthesis via Dual-Level PixelDiT Flow Matching

A high-performance generative framework for simultaneous 360° multi-view normal and depth map synthesis, combining continuous Euler ODE flow matching, 3D Rotary Position Embeddings (3D-RoPE), and dual-level patch/pixel transformers across 4-view and dense 12-view camera regimes.

Differentiable Architecture

Dual-Level Multi-View PixelDiT Architecture

Decoupling global multi-view 3D context in patch space from fine geometric normal refinement in pixel space.

3D-RoPE Embeddings

Dedicated rotary frequencies allocated across camera azimuth view indices ($V$) and spatial image coordinates ($H, W$).

Dual-Level Space

Global patch tokens capture multi-view topological consistency, while local sub-patch pixel tokens preserve sharp surface normal contours.

Flow Matching ODE

Straight probability paths connecting Gaussian noise directly to multi-view normal distributions in only 20–25 Euler integration steps.
